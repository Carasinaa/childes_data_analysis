# Automatic Syntactic Analysis of Child Speech Based on the CHILDES Corpus
This repository contains three .ipynb files with code for building graphs and analysing data for my bachelor thesis Automatic Syntactic Analysis of Child Speech Based on the CHILDES Corpus.

# Files for code usage
The files contain code for metrics and statistics computation, building graphs for visualasing metric data and error type rates, respectively.
